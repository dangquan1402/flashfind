# Code-projects benchmark

Synthetic home: 200 git repos (Rust, TS, JS, Python, Swift, Go) with sources plus realistic junk
(`node_modules`, `target`, `.venv`, `.build`/`DerivedData`, `.git` objects, gitignored logs) and
20 k non-project files under `Library/`. Seed 7. Generated by `flashfind gen-repos`; run with
`bench/run-code.sh`. Both columns use the same flashfind engine, so this measures what the
code index removes, not engine speed. Latency is per query (top 10), 5 passes.

Machine: macOS 26.5.1, Apple M5 Pro, 15 cores; load average: 143.26 128.07 85.51
